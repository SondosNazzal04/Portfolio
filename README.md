# Personal Portfolio Website - Capstone Project 1

## Project Overview
This project is a fully responsive personal portfolio website designed and developed as a foundational front-end capstone. It serves as a professional digital resume, showcasing my background in software engineering, my technical skill set, and my development projects ranging from low-level systems programming in C/C++ to full-stack web applications.

The site is built utilizing semantic HTML and modern CSS styling techniques to ensure cross-device compatibility, accessibility, and a polished user experience.

## Features
* **Semantic HTML Structure:** Cleanly separated sections including Hero, About, Skills, Projects, and Contact.
* **Light/Dark Mode Toggle:** A custom-built, JavaScript-free theme toggle utilizing the CSS `:has()` pseudo-class and CSS variables for a seamless transition between viewing modes.
* **Responsive Layout:** Built with CSS Flexbox and responsive methodologies to adapt fluidly across mobile, tablet, and desktop viewports.
* **Interactive UI:** Elegant CSS transitions and hover states applied to skill cards and project displays for enhanced user engagement.
* **Project Showcase:** A dedicated gallery highlighting diverse engineering work, including:
  * *Eduventure:* An interactive school registration hub.
  * *CuraAi:* An NLP-based student behavioral guidance platform.
  * *TheqaAi:* A secure escrow monorepo integrating open banking APIs.
  * *Webserv:* A custom HTTP/1.0 non-blocking web server.
  * *Minishell:* A custom bash-like shell environment.

## Technologies Used
* **HTML5:** For semantic document structuring.
* **CSS3:** For custom styling, animations, Flexbox layouts, and theme variables.
* **Bootstrap 5:** Utilized specifically for an optimized, collapsible mobile navigation bar.
* **FontAwesome:** For scalable vector icons.
* **Figma:** For initial wireframing and UI/UX design adaptation.

## How to View or Run the Project
This is a static front-end website, meaning no backend server or package installation is required to view it locally.

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/SondosNazzal04/Portfolio.git](https://github.com/SondosNazzal04/Portfolio.git)
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Portfolio
   ```

3. **Launch the site:**
   Simply double-click the index.html file to open it in your default web browser, or use a tool like VS Code's "Live Server" extension for hot-reloading during development.\
   you can access the website live at https://sondosnazzal04.github.io/Portfolio/
